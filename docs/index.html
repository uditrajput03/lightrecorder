Developer & Power Users

Automate Capture with URL Schemes

LightRecorder implements the lightrecorder:// URL scheme, allowing seamless integration with Raycast extensions, Alfred workflows, Apple Shortcuts, and terminal scripts.

lightrecorder://toggle Toggles recording immediately using active capture mode.
lightrecorder://toggle-copy Toggles recording and copies the resulting file path to your clipboard upon completion.
lightrecorder://open-recordings Reveals the configured recording destination folder in Finder.
Terminal & Raycast Integration
# 1. Start or stop recording from terminal
open "lightrecorder://toggle"

# 2. Stop and copy finalized file path to clipboard
open "lightrecorder://toggle-copy"

# 3. Reveal output folder in Finder
open "lightrecorder://open-recordings"

# 4. Integrate into Raycast Script Command:
# @raycast.schemaVersion 1
# @raycast.title Record Screen
# @raycast.mode silent
open "lightrecorder://toggle"

FAQ

Frequently Asked Questions

Everything you need to know about LightRecorder's features, permissions, and system architecture.

Is LightRecorder completely free?
Yes, LightRecorder is 100% free and open source under the MIT License. There are no paid tiers, trials, accounts, telemetry, or watermarks.
How does LightRecorder record system audio without extra plugins?
LightRecorder utilizes Apple's ScreenCaptureKit framework introduced in macOS 12.3 and matured in macOS 13+. ScreenCaptureKit natively provides access to system audio buffers without requiring virtual audio loopbacks or third-party kernel drivers.
Where are recording files saved?
By default, all finalized video files are saved to ~/Movies/LightRecorder. You can change this to any folder on your Mac in the LightRecorder Settings. LightRecorder maintains a security-scoped bookmark to retain access across system restarts.
What video formats and codecs are supported?
LightRecorder supports HEVC (H.265) and H.264 video compression, stored in either .mov or .mp4 containers. High, Medium, and Low bitrate presets automatically scale bits-per-pixel to match your display resolution.
What permissions does LightRecorder require?
macOS requires granting Screen Recording permissions in System Settings → Privacy & Security → Screen Recording. If you wish to capture your voice alongside system audio, microphone permissions will be prompted upon activation.
