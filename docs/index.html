LightRecorder

Minimal, open-source macOS menu bar screen recorder. Built with ScreenCaptureKit and SwiftUI. Records screen and dual audio (system + microphone) locally without background telemetry, audio drivers, or accounts.

brew install lightrecorder
Download .dmg Source

Features

  • Full screen, drag-selected area, or single application window capture.
  • System audio and microphone recorded simultaneously into isolated tracks.
  • Hardware-accelerated HEVC (H.265) and H.264 in .mov or .mp4.
  • Resolution toggle: Native Retina or 1x logical downscaling.
  • Content filtering: exclude cursor, wallpaper, menu bar, dock, or window shadows.
  • Zero third-party audio drivers (no BlackHole / Soundflower).
  • Zero analytics, telemetry, or remote network calls. 100% local.

Automation

Trigger via lightrecorder:// URL scheme from terminal, Raycast, or Shortcuts:

URL Action
lightrecorder://toggle Toggles recording with current mode
lightrecorder://toggle-copy Toggles and copies finalized file path to clipboard
lightrecorder://open-recordings Opens output folder in Finder

Requirements

  • macOS 13.0 (Ventura) or later
  • Screen Recording permission granted in System Settings
