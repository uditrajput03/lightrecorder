Overview

LightRecorder does not collect, transmit, or store any personal information, telemetry, or analytics. Everything runs locally on your Mac.

Data Handling

  • Recordings: Processed entirely in memory via Apple ScreenCaptureKit and saved directly to your local disk.
  • Telemetry: 0 trackers, 0 background daemons, 0 external network requests.
  • Accounts: No account or login required.
  • Audio: Recorded on-device using native macOS audio APIs.

Permissions

  • Screen Recording: Required by macOS to capture screen and system audio.
  • Microphone: Optional, only requested when microphone capture is enabled.
  • Disk Access: Security-scoped bookmark for your selected destination directory.
